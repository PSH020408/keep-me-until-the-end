## 0. Principles

1. **배드엔딩 = 실제로 일어나는 일.** 지어낸 화학 반응이나 과장된 수치는 쓰지 않는다. 대신 묘사는 잔혹하게: 무엇이 터지고, 어디가 하얗게 변하고, 얼마나 걸렸는지.
2. **해피엔딩 = 블랙 코미디.** 살아남는 방식이 웃기거나 어이없다. 다만 사람의 잘못이 미화되지 않게 마지막 한 줄은 쓰게 끝난다.
3. **획일화 금지.** 같은 사건이라도 종마다 결과가 다르다. 종마다 스탯 상한(cap)과 고유 특성(trait)이 있고, 상한이 요구치보다 낮으면 그 선택지는 아예 열리지 않는다. → 네온테트라가 왜가리를 물리치는 일은 없다.
4. **큰 위험은 사람이 만든다.** 물고기 스탯은 "버틸 확률"을 바꿀 뿐, 사람이 만든 상황 자체를 없애지는 못한다. 상황을 끝내는 건 주인의 행동이다(예: 뚜껑을 사 오면 점프 사건은 더 이상 안 나온다).
5. **선택지는 물고기의 감각으로 쓴다 (D&D / 「60초」 방식).** 화면에 "점프 충동 참기(영리함 40)" 같은 스탯·결과를 쓰지 않는다. 선택지는 {n}이 느끼는 것과 하려는 행동만 보여 주고, 어떤 스탯이 판정되는지, 어떤 결과가 나올지는 숨긴다. 스탯 이름은 결과가 나온 뒤에만 작게 보여 준다("영리함 +3").
6. **결과는 한 갈래가 아니다.** 같은 선택지라도 스탯 구간에 따라 결과가 여러 개로 갈린다. 스탯이 넘칠 만큼 높으면 웃긴 결과가 나온다.
7. **막힌 종에게도 할 수 있는 것 하나.** 종의 한계로 위험한 행동을 못 하는 종에게는 "바닥에 숨기" 같은 소극적인 선택지를 하나 남긴다. 죽을지 말지는 아무도 모른다.
8. **현실에 없는 탈출구는 만들지 않는다.** 약이 물 전체에 퍼지는 것, 4°C 강에서 열대어가 죽는 것처럼 피할 수 없는 일에는 선택지나 판정을 두지 않는다.

### 판정 방식
- 선택지 요구치 `need` > 종의 `cap` → **선택지가 회색으로 보이고 "{n}은 할 수 없다"** (못 하는 이유가 보이는 게 교육 포인트).
- 그 외: 성공률 = (현재 스탯 ÷ need)² , 최소 5% · 최대 95%. 요구치에 못 미쳐도 운이 있다.
- 체력·휴식 루프(GameRule [2])는 그대로 쓰되, 체력 0 사망은 "과로"가 아니라 "탈진 후 질병"으로 표기(물고기에게 과로는 어색함).

### 턴 리듬 — 수명 비례
- 어느 종이든 한 판은 약 30~40턴. 1턴의 길이는 종의 수명에 비례.
  구피 1턴 ≈ 3주 · 베타 ≈ 1.5달 · 오스카 ≈ 5달 · 비단잉어 ≈ 9달 (한 턴에 계절이 바뀜).
- 한 턴 = 아침(훈련 또는 휴식) → 낮(사건, 선택지) → 밤(숨은 판정, 결과).
- 플레이 시간은 비슷하고 서사의 밀도만 다르다.

### 배드엔딩 문장 규칙 — 관찰자 시점 · 수의학적 사실
1. **속마음 없음.** 게임 전체에서 물고기의 생각·대사("놓아 줘", "숨이 안 쉬어진다")를 쓰지 않는다. 일상 사건·선택지 포함.
2. **관찰자 시점, "~합니다" 현재형.** 죽어 가는 과정을 지금 눈앞에서 보는 것처럼 한 문장에 한 동작씩.
3. **무엇이 어떻게 망가지는지 해부·병리 그대로.** 아가미 새엽, 상피, 복강, 늑골, 척수, 측선, 수정체 같은 실제 조직 이름을 쓰고, 그 조직이 실제로 어떻게 손상되는지를 쓴다.
4. **과장 금지.** "분수처럼", "미친 듯이", "팝콘처럼" 같은 비유는 쓰지 않는다. 사실만으로 충분히 잔혹하다.
5. **물고기는 끝까지 살려고 움직인다.** 헤엄치고, 버둥거리고, 입을 벌린다. 그 움직임이 상처를 더 벌린다.
6. 병리 기전은 docs/DATA_SOURCES.md에 수의학 출처(어병학 교재 등)를 단다.

**예시**

- **대형어에게 먹힘 (오스카 합사, 네온테트라)**
  > {n}은 지느러미를 최대한 빠르게 저어 수조 구석으로 달아납니다. 오스카의 턱이 뒤에서 닫힙니다. 이빨이 가장 얇은 배 쪽을 뚫고 들어가 복강이 열립니다. 창자와 간 일부가 상처 밖으로 늘어집니다.
  > {n}은 계속 헤엄칩니다. 몸을 비틀 때마다 찢긴 옆구리가 더 벌어지고, 그 사이로 하얀 늑골이 드러납니다. 피가 물에 실처럼 풀립니다.
  > 두 번째로 물렸을 때 척추가 꺾입니다. 척수가 끊긴 뒤에도 꼬리지느러미는 한동안 반사적으로 떨립니다. 오스카는 머리부터 삼킵니다.

- **수돗물 직수 (염소, 금붕어)**
  > 잔류 염소가 아가미 새엽 표면의 상피세포를 산화시킵니다. 얇은 막이 벗겨지고, 상처를 덮으려 나온 점액이 하얗게 엉겨 붙습니다.
  > 산소를 받아들일 면적이 줄어듭니다. {n}은 수면으로 올라가 입을 벌립니다. 아가미 뚜껑이 점점 빨라지다가 불규칙해지고, 새엽 끝에서 피가 배어 나옵니다.
  > 한 시간 뒤, {n}은 옆으로 기운 채 바닥에 닿습니다. 아가미 뚜껑이 두 번 더 움직이고 멈춥니다.

- **암모니아 (무환수, 베타)**
  > 물속 암모니아가 아가미를 통해 혈액으로 들어옵니다. 아가미 새엽이 붉게 부어오르고 서로 들러붙습니다.
  > 혈중 암모니아가 뇌에 닿자 신경이 과흥분합니다. {n}은 갑자기 수조를 가로질러 돌진하고, 벽에 부딪히고, 몸을 S자로 비틉니다.
  > 경련 사이사이 {n}은 수면에서 공기를 마십니다. 라비린스 기관 덕분에 다른 물고기보다 오래 버팁니다. 그만큼 오래 경련합니다.

- **히터 고장 (고온, 코리도라스)**
  > 수온이 38도를 넘자 혈액이 실어 나를 수 있는 산소보다 몸이 쓰는 산소가 많아집니다. {n}은 바닥에서 수면까지 쉬지 않고 오르내리며 공기를 삼킵니다.
  > 근육 단백질이 굳기 시작하면서 움직임이 뻣뻣해집니다. {n}은 옆으로 쓰러진 채 가슴지느러미만 움직입니다.
  > 죽은 뒤에도 수온은 계속 오릅니다. 아침에 주인이 본 {n}의 눈은 수정체가 익어 하얗게 흐려져 있습니다.

   종: 전 종. 점프 확률은 종마다 다름 (아로와나 최고, 오란다·유금 최저)

   **화면 문구**
   > 불이 꺼졌다. 수면 위가 이상하게 넓어 보인다. 천장 쪽에서 작은 날벌레 하나가 맴돈다.

   > ① 수면 아래에서 벌레를 계속 올려다본다
   > ② 지느러미를 접고 몸을 낮춘다
   > ③ 바닥 돌 틈으로 내려간다   ← 점프를 못 하는 종에게도 항상 열림

   **숨겨진 판정과 결과**
   - ① 올려다보기 → 아로와나·스네이크헤드·베타·코메트는 점프 충동 판정(영리함). 성공하면 영리함 +3, 실패하면 **점프** 결과표로.
     오란다·네온 등 점프 못 하는 종은 그냥 밤이 지나감(영리함 +1).
   - ② 몸 낮추기 → 근성 +2. 점프 확률 크게 감소. 단, 30% 확률로 "수면 쪽에서 무언가가 들여다본다" → 고양이 사건으로 이어짐.
   - ③ 바닥 숨기 → 점프 없음. 고양이 사건이 와도 영리함 판정 보정. 대신 아무것도 오르지 않음(안전하지만 성장 없음).

**주인 교체 규칙**
- 어느 유형이든 한 생 중간에 주인이 바뀔 수 있다: 파양·당근 나눔·이사·입원·사망·이별·폐업.

- 주인이 바뀔 때마다 운송·물맞이 사건 한 번 (봉지, 이삿짐 트럭 등).
- 주인 교체 이력은 엔딩 후 돌아보기에 "{n}의 주인들" 목록으로 표시.

### 주인이 배우는 방식 (Owner learning)
- **계기 = 아슬아슬한 사건.** {n}이 간신히 살아남은 사건(점프 후 컴백, 약품 버티기 성공, 반쯤 죽었다 회복 등)이 끝나면 주인 학습 판정.
- 학습에 성공하면 그 사건의 원인이 사라진다: 뚜껑 구매 → 점프 사건 종료 / 약 라벨 확인 → 약품 사건 종료 / 히터 커버 → 화상 사건 종료.
- **주인 유형마다 다르다 — 결국 사람이 하는 일.**

| 주인 유형 | 아슬아슬한 사건 후 배울 확률 | 배우는 모습 |
|---|---|---|
| 고수 (expert) | 매우 높음 | 그날 바로 주문. 재발 없음 |
| 공부하는 초보 (learner) | 높음 | 검색 → 커뮤니티 질문 → 며칠 뒤 해결 |
| 브리더 | 중간 | 종어(돈 되는 개체)일 때만 배움 |
| 무던한 주인 (content) | 낮음 | "이번엔 운이 좋았네" |
| 대충 주인 (casual) | 매우 낮음 | 다음 주에 같은 일 반복 |
| 선물받은 주인 (gift) | 낮음 | 원래 주인(선물한 사람)에게 물어봐야 앎 |
| 관종 | 조회수 떨어질 때만 | 댓글에 지적이 많으면 배우는 척 영상 |
| 방치파 | 0 | 사건을 알아채지도 못함 |
| 약품 연금술사 | 거꾸로 배움 | 약을 하나 더 산다 |
| 테크 브로 | 높지만 과함 | 센서를 하나 더 단다 → 새 고장 사건 |
| 악질 브리더 | 0 | — |
| 효도 어항 할머니 | 중간 | 손주가 와야 고침 |
| 탕비실 어항 | 거의 0 | 책임자가 없음. 누군가 공지문을 붙임 |

## 10. Truth tiers — 출처 등급 (구술 18)

모든 사건·엔딩에 등급 하나를 붙인다. 출처가 필요한 건 "사실이라고 말하는 층"뿐이다.

| 등급 | 뜻 | 출처 | 화면 표시 |
|---|---|---|---|
| 📌 사실 | 실제로 일어나는 일 + 병리·기전이 확인됨 | **필수** (DATA_SOURCES.md) | 엔딩·돌아보기에 "실제로 일어나는 일" 표시와 출처 링크 |
| 🔸 있을 법한 일 | 기전은 사실, 구체적 장면은 지어냄 (탕비실 과식, 법회 대야 등) | 기전만 확인. 숫자·"실제로 ~한다" 문장 금지 | 표시 없음 |
| 🎭 이야기 | 블랙 코미디·과장 (점프 컴백, 주인 역사육, 저수지의 괴물 등) | 불필요 | 😂 표시 — 지어낸 이야기임을 숨기지 않음 |

규칙
- 배드엔딩은 최소 🔸. 기전이 틀렸거나 확인 안 되면 🎭로 내리는 게 아니라 **고치거나 뺀다** (예: 탄산수 삼투압 ✕).
- 🎭는 해피엔딩과 코미디 결과에만 쓴다. 죽음을 웃기게 지어내지 않는다.
- 출처 확인 결과 📌 → 🔸로 내려가는 건 괜찮다 (문장에서 사실 단정·숫자만 뺌).

모드별 배분 (기존 현실/이야기 모드 사용)
| | 현실 모드 | 이야기 모드 |
|---|---|---|
| 📌 사실 | 많이 | 보통 |
| 🔸 있을 법한 일 | 보통 | 보통 |
| 🎭 코미디 | 드물게 | 많이 |
| 🎭 대형 코미디 (주인 역사육 등 현실성을 크게 깨는 것) | 안 나옴 | 나옴 |

## 9. Decisions log (구술 평가 결과, 2026-10-13)
1. 종 한계로 막힌 행동 대신 **"바닥에 숨기" 같은 소극적 선택지를 항상 하나** 남긴다.
2. 점프 같은 반복 위험은 **주인이 뚜껑을 사면 끝난다** (주인 행동이 해결책).
3. 선택지는 스탯·결과를 숨기고 **물고기의 감각으로 쓴다** (D&D / 「60초」).
4. 점프 결과는 힘 구간별로 갈림: 내장 파열 / 반반 / 복귀 / **cap 근처면 펄쩍 컴백 코미디**.
5. 약품 사건: 약을 피하는 선택지 없음(어차피 퍼짐). **영리함+애교로 주인에게 어필 → 실패 시 근성으로 버티기.**
6. 방생 법회 겨울 열대어: **판정 없이 즉시 사망.** 현실에 없는 탈출구 금지.
7. 블랙 코미디 해피엔딩: **마지막 쓴 한 줄 유지.**
8. 주인 학습 계기 = **아슬아슬한 사건 후**, 확률은 **주인 유형별로 다르게.**
9. 턴 = **수명 비례** (한 판 30~40턴).
10. 문장 = **속마음 전면 삭제, 관찰자 시점 "~합니다" 현재형, 해부·병리 사실로 잔혹하게** (대형어 포식 예: 달아남 → 복강 물림 → 늑골 드러난 채 버둥거림 → 척추 꺾임).
11. 종 전용 훈련마다 **숨은 부작용** 있음.
12. 먼저 넣을 주인 유형: **당근 나눔 돌려막기, 방생 법회 신도, 탕비실·교실 어항, 풍수·인테리어 어항, 무환수·무여과 신봉자, 악질 브리더.**
13. 포식 예시 문장(오스카 → 네온)을 **모든 배드엔딩의 문체·수위 기준**으로 삼는다.
14. 배드엔딩 끝에 **주인 유형별 사후 한 줄**을 붙인다.
15. 기존 게임 문구의 물고기 속마음(fishgrow.js·fishchoice.js에 3곳)은 코드 작업 때 삭제한다.
16. 주인 유형 합침: 관종+대형어 채널 → **영상·SNS 주인**, 아이 있는 집+경품·선물 → **얼떨결에 키우게 된 집**, 악질 브리더+번식장 → **번식장**. 의욕 과다 초보는 따로.
17. 보류했던 유형 **전부 추가** (방치파·연금술사·스마트홈, 낚시 미끼·체험 카페, 효도 어항·이별 커플, 언박싱 유튜버·수족관 직원) → 총 22유형.
18. **어느 유형이든 한 생 중간에 주인이 바뀔 수 있다.** 애교가 높으면 더 나은 주인을 만날 확률 ↑.
19. 사건 카탈로그(docs/fish_events/, 327개 + 해피엔딩 31개)의 형식·수위 **승인** (샘플 EV-OWB-08 「법회가 끝날 때까지」 기준).
20. 해피엔딩 HAP-42 같은 잔잔한 감동형은 의견 없음 → 현재 비율(대부분 블랙 코미디, 일부 감동형) 유지.
21. 엔딩 분류 3종: 🔴 배드 · 😂/🟢 해피 · 🕊 **보내 줌**(회복 불가 병에서 주인이 정향유로 안락사 — 고수·공부하는 초보·수족관 직원·할머니 주인만. 대충 주인은 살아 있는 채 변기 → 배드).
22. 출처 등급 3단계(📌 사실 · 🔸 있을 법한 일 · 🎭 이야기) 도입. 출처는 📌만 필수. 이야기 모드는 🎭가 많고, 현실 모드는 🎭가 드물며 대형 코미디는 이야기 모드 전용.
